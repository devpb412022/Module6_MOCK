จับคู่ที่ออกบ่อย

Vickers vs Rockwell
Vickers = เพชรปิรามิด วัดเส้นทแยง / Rockwell = ลูกเหล็กหรือกรวย Brale วัดความลึก
Thrust vs Radial
Thrust = ขนานเพลา (axial) / Radial = ตั้งฉากเพลา
Coarse vs Fine
Coarse = เกลียวน้อยต่อนิ้ว / Fine = เกลียวมาก
Cherry Lock vs Max
Lock = เห็นปลอกล็อกตลอด / Max = เห็นหลังขึ้นรูป
Metric vs Whitworth
Metric/Unified = 60° / Whitworth = 55°
Anodic vs Cathodic
Mg anodic สุด (ผุก่อน) / Gold cathodic สุด
